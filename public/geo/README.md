# Natural Earth base map

Public-domain map data used by the `map` tool. Source: [Natural Earth](https://www.naturalearthdata.com/), via the [natural-earth-vector](https://github.com/nvkelso/natural-earth-vector) GeoJSON export.

| File | Source layer |
| --- | --- |
| `ne_110m_land.geojson` | `ne_110m_land` |
| `ne_50m_land.geojson` | `ne_50m_land` |
| `ne_110m_admin_0_countries.geojson` | `ne_110m_admin_0_countries` |
| `ne_110m_rivers_lake_centerlines.geojson` | `ne_110m_rivers_lake_centerlines` |
| `ne_110m_lakes.geojson` | `ne_110m_lakes` |

Natural Earth terms: https://www.naturalearthdata.com/about/terms-of-use/ — public domain, no permission needed.

The base map is simplified. Modern borders are drawn only when a map asks for them; historical boundaries come from the polygons in the map's own spec.
